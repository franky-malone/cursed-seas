1. Copy src/components/InitiativeTracker/* into your project under that same path.
2. Copy docs/initiative-tracker.mdx into docs/.
3. DELETE the old src/pages/initiative-tracker.jsx and src/pages/initiative-tracker.module.css (or move them out of src/pages). This prevents duplicate routes.
4. In sidebars.js remove the old {type: 'link', label: '⚔️ Initiative Tracker', href: '/initiative-tracker'} entry. The new doc is included by the autogenerated sidebar. Its sidebar_position: 9999 normally puts it last. If your sidebar is manually maintained, add {type: 'doc', id: 'initiative-tracker'} as the final item instead.
5. Remove the separate Initiative Tracker navbar item if you prefer access only through Wiki. Keep the Wiki docSidebar navbar item.
6. npm run build, then npm run start. Your previous localStorage data remains under cursed-seas-initiative-v1, provided the URL origin is unchanged.
NOTE: The docs/ slug assumes the existing docs routeBasePath is '/' (as suggested by your existing routes). If docs routeBasePath is '/docs', the new URL will be /docs/initiative-tracker and sidebar navigation will point there.
